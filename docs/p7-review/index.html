Found while capturing

Fix these before (or with) P7

  • Tailwind isn't doing anything. app/globals.css uses the v3 @tailwind base/components/utilities lines, but the project runs Tailwind v4, which ignores them. The compiled CSS has no utility classes and no base reset. Effects you can see in the screenshots: text without an inline font falls back to Times (the PR #3 feed rows), buttons without an inline colour render black text (the Profile menu reads at 1.21:1), and pb-16 never applies, so the bottom of every tab sits under the tab bar. Smallest fix: add explicit base rules (body{font-family:var(--font-montserrat)}, button,input,textarea,select{font:inherit;color:inherit}) and a real bottom inset, then decide separately whether to switch on v4's full reset with @import "tailwindcss".
  • Venue banner photos never show. components/HeroCarousel.tsx set both backgroundImage and background: undefined; React 19 writes the empty shorthand and wipes the photo, so Home and Manage Banners show a black hero. Fixed in this PR (one style key instead of two), verified in the capture harness.
  • Members shows icon names as words. On Members, a title's lucide icon prints as text: "star Regular".
  • Light theme hides the active tab. The tab bar uses lightTheme.tabBarBg and theme.accent, but lightTheme === darkTheme (both are the same var() map), so in light both resolve to ink #231E20: the active "Home" measures 1.00:1.
  • Rows run off the right edge at 390px: Messages (time and preview are clipped), the Admin venue card's action links, and the PR #3 feed composer's Post button and filter chips.
Recommendations

What to change and what to keep

Change

  • Put every card, list group and sheet on the GlassPanel / Card primitives (glass fill, 1px glass border, top rim, black depth shadow). Today most screens use flat surfaceRaised blocks.
  • Make every icon-only control a GlowIconButton at 44 × 44 or larger: back, profile, carousel arrows, approve/deny, reorder, delete.
  • Replace the History pink-to-orange gradient panel with glass rows on the dark ground. The gradient is the loudest thing in the app and isn't part of P1.
  • Remove the teal tints (ProfileTab "Looking for", Complete Profile, MapTab badge, Messages empty state, OrganizerWelcomeModal) and use neutral glass with the accent fill for selected state.
  • Use SectionHeader (uppercase, tracked, 1.5px rule) for section titles such as WHO'S HERE, TITLES AT THIS VENUE, JOIN REQUESTS.
  • On Home, collapse the six organizer pills into one "Manage venue" glass row, and move History · Rewards · Connect up to sit under the hero as glass tiles. Guests see the venue and the feed sooner.
  • Show likes as a number that turns red when you've liked it, with no heart and no glow, as the P1 spec says. The PR #3 row uses a pink heart today.
  • Frost the tab bar (glass over the content) and float it 12px off the edges.
  • Keep bloom to the one top-edge band already on body. Don't add bloom behind cards or buttons.
  • Swap the admin venue card's five text links for a 4-column grid of 48px icon tiles with labels.
  • Venue join mode: a two-option segmented control (Request / Auto) instead of a "Switch to…" button.

Keep

  • The token system (app/globals.css + lib/theme.ts): it already carries the glass roles, so P7 is mostly applying them.
  • The neutral near-white primary button. It reads as the one clear action on each screen.
  • The Report page structure. Its uppercase card titles and big numerals already match the P1 look; it only needs glass cards.
  • Green only for the "Active" state and online dots, with dark text on it (9.56:1).
  • The locked "Unlock who's here" overlay from P1 (blur + padlock + two lines).
  • Montserrat and the P1 type scale.
  • Real photos as the only colour source on Home: the venue banner and avatars carry the mood, the chrome stays monochrome.
